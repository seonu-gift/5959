5등급제 내신, 9등급제로 보면 어느 정도일까요?

진정성입시연구소가 막연했던 성적 감각을 조금 더 선명하게 확인할 수 있도록
내신 변환기를 만들었습니다.

현재 받은 내신을 9등급제 기준으로 환산해 대략적인 위치를 가늠해볼 수 있고,
목표 등급을 입력하면 남은 학기 동안 어떤 성적 흐름이 필요한지도 확인할 수 있습니다.

다만 이 수치는 절대적인 기준이 아니라 참고용 추정치입니다.
입시 전략은 학교별 분포, 과목별 특성, 학생부 전체 맥락까지 함께 보아야 합니다.
따라서 변환 결과는 참고 지표로만 활용하시기 바랍니다.
